# Air Dombyra: P1 (распознавание рук)

P1 превращает видео с камеры в `HandFrame` на каждом кадре. Удары и звук делает P2.

```
npm install
npm run dev      # http://localhost:5173 (или порт, который выведет Vite)
npm test         # логика без камеры
node scripts/make-demo.mjs   # пересоздать recordings/synthetic-demo.json
```

## Контракт (src/p1/types.ts)

```ts
type HandFrame = {
  t: number;         // мс, строго растёт
  neck?: HandData;   // левая рука на экране (гриф), undefined если не видна
  strum?: HandData;  // правая рука (бой), undefined если не видна
  fret: number;      // 0 = открытые / нет руки, 1..6
  muted: boolean;    // кулак на левой руке
};
type HandData = {
  points: {x,y,z}[]; // 21 точка, сглаженные, 0..1, уже зеркальные
  palm: {x,y};       // центр ладони
  size: number;      // размер ладони (в долях высоты кадра), для «слишком далеко»
};
```

## Для P2

Вживую:
```ts
import { bus } from "./main";               // или window.p1.bus в DevTools
bus.subscribe((frame) => strumDetector.push(frame));
```

По записи, детерминированно, без камеры:
```ts
import { parseRecording, frames } from "./p1";
const rec = parseRecording(fs.readFileSync("recordings/xxx.json", "utf8"));
for (const f of frames(rec)) strumDetector.push(f);
```

В браузере: «Открыть запись…» проигрывает JSON в реальном времени через тот же `bus`.

## Запись видео

«Камера», затем «● Записать видео» → играть → «■ Остановить» → под кнопкой появляется превью с «💾 Сохранить видео» (в Chrome/Edge — окно «Сохранить как», иначе обычная загрузка) и «Удалить». Файл `air-dombyra-<время>.mp4` (или `.webm`, если браузер не пишет MP4): всё, что на холсте — камера, домбыра, струны, руки, эффекты — и звук домбыры (`src/capture.ts`, `MediaRecorder` + `canvas.captureStream` + аудио-выход Tone.js).

Запись HandFrame в JSON (`p1/recorder.ts`) осталась в коде для тестов и «Открыть запись…», кнопки для неё больше нет.

## Устройство

| Файл | Что делает |
|---|---|
| `p1/live.ts` | камера + MediaPipe HandLandmarker (GPU → CPU fallback), модель и wasm лежат локально в `public/` |
| `p1/engine.ts` | чистый конвейер: зеркало → роли → сглаживание → лад → mute |
| `p1/roles.ts` | левая на экране = гриф; идентичность по ближайшей прошлой позиции, handedness MediaPipe игнорируется |
| `p1/oneEuro.ts` | One Euro Filter; у руки боя сглаживание слабее, чтобы не терять быстрые удары |
| `config.ts`, `instrument.ts` | общая геометрия домбыры (гриф, лады, 2 струны) и строй D3/G3: по ней и рисуем, и распознаём |
| `p1/aim.ts` | (опция «Гриф за левой рукой», по умолчанию выкл.) гриф поворачивается к левой руке вокруг точки боя |
| `p1/grab.ts` | кнопка «Двигать домбыру» → щипок правой руки (большой + указательный) на кружке у хвоста корпуса тащит домбыру, щипок левой руки и поворот ладони вокруг корпуса меняет наклон → «Зафиксировать» сохраняет позицию и наклон в localStorage. Положение за кадр: `HandFrame.pose`; в режиме перемещения `placing: true` |
| `p1/fret.ts` | центр ладони (синяя точка на руке) проецируется на гриф; 12 хроматических ладов одинаковой ширины; гистерезис 15% ширины лада, смена лада сразу (≈55 мс после пересечения границы, без дребезга — проверено симуляцией с шумом трекинга) |
| `p1/mute.ts` | кулак = ≥3 пальца сложены в ладонь (кончик ближе к запястью, чем своя костяшка; переключение после 4 кадров подряд). Глушит только кулак **вне ладов**: кулак на ладу — это рука, зажимающая лад (`engine.ts`) |
| `p1/recorder.ts`, `p1/replay.ts` | запись в JSON и воспроизведение |
| `p1/overlay.ts` | скелеты, домбыра, подписи |
| `p2/strum.ts` | детектор боя: «медиатор» — кончик указательного (ноготь бьёт по струнам) в координатах грифа; короткие пропуски трекинга (до 150 мс, смаз на быстром ударе) перекрываются, а не сбрасывают удар; незасчитанное пересечение подписывается причиной (медленно / вне зоны / повтор); для каждой струны своё пересечение с гистерезисом и точным временем между кадрами; струна звучит сразу при пересечении, пересечения одного взмаха собираются в `strum` со списком струн (`[0]`, `[1]` — одна струна, `[0,1]`/`[1,0]` — обе) |
| `p2/audio.ts` | по голосу на струну (струна монофонична, как настоящая): записанные щипки через `Tone.Sampler` (транспонирует под лад), пока грузятся — PluckSynth. Под домбыру: highpass 150 Гц (тоньше корпус), +4 дБ на 2.5 кГц (звон), шумовой «удар пальца» 30 мс в начале каждого боя, вторая струна через 10–25 мс после первой (реальная задержка между пересечениями, в этих пределах). Звучание «долгое» или «короткое» (0.5 с, как домбыра) — список на странице. `lookAhead = 0`; громкость от скорости; кулак — глухой «чк» и глушение |
| `p2/fx.ts` | вибрация струн, названия нот, метка медиатора, подпись последнего удара |

### Звуки

Свободных записей отдельных нот домбыры нет (Freesound — 0, Wikimedia — только произношение слова, остальное платные Kontakt-библиотеки). Пока стоит нейлоновая гитара — ближе всего к жильным струнам домбыры: 11 нот D3–G#4 из [tonejs-instruments / guitar-nylon](https://github.com/nbrosowsky/tonejs-instruments) (Nicholaus P. Brosowsky), лицензия [CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/). Все в строю (±10 центов), атака ≤4 мс, до 4 с звучания + лёгкая реверберация. Лады хроматические, как у гитары: 12 ладов, октава на струну (D3–D4 и G3–G4).

Заменить на настоящую домбыру: записать на телефон по одному щипку нескольких нот (например, открытые D3 и G3 и пару ладов на каждой), затем
```
afconvert -f WAVE -d LEI16@44100 -c 1 note.m4a note.wav   # macOS, для каждого файла
node scripts/prepare-samples.mjs папка-с-wav
```
Скрипт сам определит высоту, отрежет тишину до атаки, нормализует и перезапишет `public/samples/` + `manifest.json`. Код менять не нужно.

Выбор струн: список «Струны» на странице — обе / только верхняя (D) / только нижняя (G) (`strum.only`); выключенная струна рисуется пунктиром и полностью игнорируется.

Настройки боя: `DEFAULT_STRUM` в `src/config.ts` (зона боя на корпусе, порог против дрожания, мин. скорость, «слабый» удар, окно группировки, защита от двойного срабатывания).

Параметры для подстройки (`DEFAULT_ENGINE_OPTIONS` в `engine.ts`): `neckFilter`/`strumFilter` (minCutoff ниже → плавнее, beta выше → меньше задержка), `muteFrames`. Геометрия инструмента: `DEFAULT_INSTRUMENT` в `src/config.ts`. Наклон и высоту домбыры можно менять слайдерами на странице.
