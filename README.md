# Air Dombyra — домбыра в воздухе

Веб-приложение: играйте на казахской домбыре руками перед обычной веб-камерой — без клавиатуры, мыши и установки. Левая рука зажимает лады на нарисованном грифе, правая бьёт по струнам, приложение звучит, подсвечивает, что распознало, учит мелодиям и **подсказывает, как исправить ошибку**.

**Направление:** свободный вариант — музыкальный инструмент в воздухе.
**Демо:** _ссылка на деплой_ · всё работает в браузере, видео с камеры никуда не отправляется.

---

## Как запустить

Нужен Node.js 20+ и браузер Chrome / Edge / Safari с веб-камерой.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты логики (без камеры)
npm run build      # продакшен-сборка в dist/
```

1. Откройте страницу и нажмите **«Включить камеру»**, разрешите доступ.
2. Встаньте так, чтобы обе руки были в кадре (~1 м от камеры, свет спереди).
3. Играйте свободно или выберите упражнение в блоке **«Учиться»**.

Кнопка **«✋ Жесты»** в шапке открывает памятку по всем жестам.

## Сценарий: от начала до результата

1. **Старт** — «Включить камеру». Подсказка сверху просит показать обе руки и говорит, какая рука пропала из кадра.
2. **Учиться** — выбираете упражнение (3 мелодии). Под видео — ноты урока, на домбыре золотом подсвечены нужный лад и струна.
3. **Игра** — правильная нота засчитывается и урок идёт дальше; **неправильная не засчитывается**: «↺ Ещё раз» и конкретная подсказка, что поправить.
4. **Результат** — окно итогов: точность, число попыток, время, самая частая ошибка с советом, личный рекорд (сохраняется в браузере). «Ещё раз» или «Следующее →».

Упражнения (домбыра здесь — 12 ладов; мелодии, не помещающиеся на верхнюю струну, переносятся на нижнюю с теми же высотами нот):

| Упражнение | Лады | Струна |
|---|---|---|
| 1 | 7 · 7 · 8 · 7 · 3 · 5 · 7 · 12 | верхняя (D) |
| 2 | 3 · 5 · 8 · 7 · 6 · 5 · 8 · 7 · 3 (исходно 10-12-15-14-13-12-15-14-10) | нижняя (A) |
| 3 | 5 · 5 · 7 · 8 · 7 · 10 · 8 · 7 | верхняя (D) |

Каждое упражнение — на одной струне: вторая струна на время урока выключается.

## Жесты (каждый вызывает своё действие)

| Жест | Действие | Как распознаётся |
|---|---|---|
| Левая ладонь на грифе | выбор лада 1–12 | центр ладони проецируется на наклонный гриф; гистерезис на границах ладов, чтобы не дрожало |
| Правая рука: взмах указательным пальцем через струны | звук струны / двух струн | пересечение линии каждой струны кончиком пальца, с точным временем между кадрами; вниз и вверх — разные направления удара |
| Кулак левой руки вне ладов | заглушить струны | ≥3 пальца сложены в ладонь (кончик ближе к запястью, чем костяшка), 4 кадра подряд |
| Обе открытые ладони, 1 с неподвижно | вкл/выкл режим перемещения домбыры | все пальцы выпрямлены у обеих рук + неподвижность; вокруг ладоней заполняется кольцо |
| Щипок правой (большой + указательный) в кружке ✥ на корпусе | переместить домбыру | расстояние между кончиками в размерах ладони, с учётом глубины; начинается только в кружке |
| Щипок левой в кружке ⟲ посередине грифа | повернуть домбыру | то же; угол меняется на столько, на сколько рука повернулась вокруг корпуса |

**Обратная связь:** скелеты рук (синий — левая, оранжевый — правая; легенда всегда под видео), подсветка текущего лада и номер лада над рукой, вибрация задетой струны и название ноты, стрелка удара («↓ обе струны»), след кончика пальца, подсказки сверху.

## Режим «ошибка» (твист)

Приложение замечает неверные и неточные движения и говорит, **что именно** поправить.

| Ошибка | Как обнаруживается | Что видит пользователь |
|---|---|---|
| Не тот лад | лад в момент удара ≠ нужному | «Вы на 5-м ладу, нужен 7-й: сдвиньте левую руку на 2 лада к корпусу» (направление и число ладов) |
| Ладонь не на грифе | лад = 0 в момент удара | «Поставьте ладонь на гриф, на 7-й лад» |
| Не та струна | удар не задел нужную струну | «Нужна нижняя струна — ведите палец через неё» |
| Кулак глушит струну | в момент удара распознан кулак | «Разожмите кулак левой руки — сейчас он глушит струны» |
| Слишком медленный удар | скорость пересечения струны ниже порога | подпись у пальца «медленно» |
| Удар не над корпусом | пересечение над ладами / вне инструмента | «вне зоны боя» |
| Рука дрожит на струне | удар не прошёл нужной длины | «короткий взмах» |
| Рука ушла из кадра | рука не видна > 0,5 с | «Левая рука вне кадра — верните её на гриф» |

Неправильная нота в уроке **не засчитывается**: урок ждёт, пока её сыграют верно. В итогах — самая частая ошибка и совет, как её избежать.

## Техническая реализация

Весь цикл «камера → распознавание → звук → отрисовка» — обычный TypeScript без фреймворков, вызывается на каждый кадр видео (`requestVideoFrameCallback`); звук запускается прямо из обработчика кадра, без задержек рендера.

| Модуль | Что делает |
|---|---|
| `src/p1/live.ts` | камера + MediaPipe HandLandmarker (GPU, запасной CPU), модель и wasm лежат локально |
| `src/p1/engine.ts` | конвейер кадра: зеркало → роли рук → сглаживание (One Euro) → лад → глушение → жесты |
| `src/p1/roles.ts` | какая рука левая/правая: роль «прилипает», пока рука в кадре; новая рука — по положению на домбыре; склейка двойного распознавания |
| `src/p1/fret.ts` | лад по центру ладони, гистерезис, смена лада ≈55 мс после пересечения границы (проверено симуляцией с шумом) |
| `src/p1/mute.ts`, `gesture.ts`, `grab.ts`, `aim.ts` | кулак, жест «обе ладони», перемещение/поворот щипком, (опц.) гриф за рукой |
| `src/instrument.ts`, `src/config.ts` | общая геометрия домбыры: по ней и рисуем, и распознаём |
| `src/p2/strum.ts` | детектор удара: отдельное пересечение на каждую струну, гистерезис от дрожания, мост через пропуски трекинга, причины отказа |
| `src/p2/audio.ts` | Tone.js: по голосу на струну, записанные щипки, фильтры «под домбыру», шум удара пальца, вторая струна через 10–25 мс |
| `src/lesson/*` | упражнения, раскладка под 12 ладов, судья и подсказки, итоги и рекорды |
| `src/capture.ts` | запись видео со звуком (MediaRecorder) |

**Своя логика команды:** проекция руки на гриф и лады, детектор боя по струнам, роли рук, глушение, жесты (обе ладони, щипки), судья урока и подсказки, звуковой движок. Готовые библиотеки дают только точки руки и воспроизведение звука.

**Тесты:** `npm test` — 70+ тестов (лады, роли рук, жесты, удары по струнам, уроки), без камеры.
